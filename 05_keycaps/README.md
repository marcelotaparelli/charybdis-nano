# Charybdis Nano 3x5 — DES-compatible keycap print pack v1

Pacote de teste com **35 keycaps MX** para Charybdis Nano 3x5 + Skeletyl:

- 10 × perfil superior R4
- 10 × perfil home R3
- 10 × perfil inferior R2
- 5 × polegares
- Total: 35

Distribuição:
- esquerda: 15 principais + 3 polegares = 18
- direita: 15 principais + 2 polegares = 17

## O que mandar para impressão

Opção mais simples: `plates/full_set_35.stl`.

Se a gráfica preferir peças separadas, envie a pasta `individual/` inteira.

Antes do conjunto completo, recomendo imprimir `masters/MX_stem_fit_coupon.stl` para validar o encaixe no stem Cherry MX da impressora/resina usada.

## Observação

Este é um **pack de teste DES-compatible / DES-inspired**, gerado especificamente para validar ergonomia e impressão. Não é uma exportação oficial dos arquivos Pseudoku. Os parâmetros de escultura foram informados pelo projeto aberto PseudoMakeMeKeyCapProfiles e por isso o pack inclui atribuição e licença GPL-3.0.
